# Version 1.2.0

This version adds the published 29-isolate pyocin panel, two separate target cohorts, and accession-checked sequence analyses with IUPred3, Clustal Omega, and InterProScan. In the matched numeric MIC data, SX1 had a lower MIC than SX2 in 14 of 17 non-tied isolate pairs. The files include the source data, all tested comparisons, code, tool outputs, and figures.
